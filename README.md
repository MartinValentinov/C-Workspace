# My First Steps in C

This repository contains my **first experiments and projects in the C programming language**.  
It documents my journey learning C, from basic programs to slightly more structured exercises.  

---

## About

This repo showcases:

- Basic C syntax: variables, loops, and conditions  
- Functions and modular programming  
- Pointers and memory management  
- Simple file I/O  
- Small projects and exercises to practice C fundamentals  
- Compilation and debugging on macOS/Linux

It is primarily a **learning playground** to understand how C works.

---

## How to Compile and Run C Programs

You can compile C programs using `gcc` or `clang`. Examples:

```bash
# Compile a single C program
gcc -o hello_world src/hello_world.c

# Run the program
./hello_world

# Compile a multi-file program
gcc -o my_program src/main.c src/utils.c
./my_program
